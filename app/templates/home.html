Get started

Step 1

List Documents

Browse all files in your configured input folder. Filter by name or extension, check sizes and dates, and confirm you have everything you need before proceeding.

  • Full list with file details
  • Filter and search documents
  • Sort by name, date or size
Browse documents
Step 2

Rename Documents

Apply a consistent naming convention to one or many documents at once. Always preview the new names before confirming — nothing is changed until you approve.

  • Rename one or many at once
  • Preview before/after names
  • No changes until confirmed
Start renaming

Package Documents

Select the documents you want to deliver and generate a ZIP package ready to send. A manifest file is included automatically with the full list of contents.

  • Select individual documents
  • ZIP package generated instantly
  • Manifest included automatically
Build a package
